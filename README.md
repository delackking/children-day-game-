# CARNIVAL — The Virtual Children's Day

A browser-based, multiplayer 3D Indian Children's Day Carnival built with React, TypeScript, Three.js, Rapier 3D Physics, Express, and Socket.IO.

## Quick Start
```bash
npm install
npm run dev
```
Open `http://localhost:3000` to host a private carnival room or join via room code / invite link (`/?room=CODE`).

See `/docs/ARCHITECTURE_AND_GUIDE.md` for full setup, testing, deployment, Host Control Center instructions, and asset licensing details.
